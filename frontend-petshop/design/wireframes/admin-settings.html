Tất cả lưu bằng 1 lệnh PATCH /api/v1/settings {settings: {key: value, …}} (upsert theo key, giá trị là chuỗi). Trang public đọc GET /settings?keys=…. Mỗi ô ghi key bên dưới để code frontend dùng đúng tên. Lưu xong → revalidate trang chủ.
