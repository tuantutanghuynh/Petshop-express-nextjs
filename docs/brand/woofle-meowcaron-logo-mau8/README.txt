svg/  file vector, phóng to bao nhiêu cũng nét. Chữ đã chuyển thành nét vẽ, không cần cài font.
  logo-ngang.svg    logo + tên + "Siêu thị của chó mèo" — dùng trên thanh menu nền trắng

  avatar.svg        hình tròn — ảnh đại diện mạng xã hội
  favicon.svg       mèo macaron — icon trên tab trình duyệt
