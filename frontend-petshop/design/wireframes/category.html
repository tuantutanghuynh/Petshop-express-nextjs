Thức ăn cho mèo

Hạt, pate và bánh thưởng cho mèo con, mèo trưởng thành và mèo lớn tuổi.

Ảnh danh mục
Dữ liệu: tên + mô tả từ Category (name, description) — URL dự kiến /danh-muc/[slug]. Category chưa có endpoint "theo slug" → lấy từ GET /api/v1/categories rồi lọc theo slug (hoặc thêm GET /categories/:slug). Không tồn tại → notFound() (404 thật).

Dữ liệu: GET /api/v1/products?categorySlug=…&page=…&pageSize=24 → meta { page, pageSize, total }. Phân trang bằng URL thật ?page=2 (không infinite scroll — rule SEO). Trang ?page≥2: canonical về trang 1 hoặc self-canonical, không đưa vào sitemap. Server Component đọc searchParams (Next 16: Promise).
Trạng thái: loading = 8 thẻ skeleton · rỗng = "Danh mục chưa có sản phẩm" + link về Tất cả sản phẩm · lỗi API = khối báo lỗi + nút Thử lại.
⚠ Tìm kiếm ở header: GET /products công khai chưa có tham số q (chỉ admin list có search). Cần thêm q (+ index trigram cho ILIKE) trước khi bật ô tìm kiếm; trang kết quả /tim-kiem?q= phải noindex.
